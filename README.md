# usagi-python 🐰

치이카와(ちいかわ)의 **우사기 · 치이카와 · 하치와레**처럼 대답하는 터미널 대화 라이브러리.
의존성 없이 파이썬 표준 라이브러리만 사용합니다.

> 비공식 팬 프로젝트이며 원작(나가노)과 관계없습니다.

```
우사기> 야하!
나> 배고파
우사기> 쥬르리 쥬르리!

하치와레> 안녕~!
나> 내일 시험이야
하치와레> 어떻게든 되라앗!
나> 오늘 쉬는 날이래?
하치와레> 오늘 쉬는 날이래…라는 거야!?

치이카와> 후!
나> 벌레다
치이카와> 이얏!
```

## 터미널에서 사용

캐릭터마다 명령이 있습니다: `usagi`, `chii`, `hachi` (또는 `usagi -c chii`).

```bash
usagi                  # 우사기와 대화
chii                   # 치이카와와 대화
hachi                  # 하치와레와 대화
hachi -e               # 대답 옆에 번역 표시 (대화 중 /explain 으로 토글)
usagi --no-art         # 시작 화면 아트 숨기기
chii say 배고파         # 한 문장만 대답
hachi translate 괜찮아! 괜찮아!   # 번역
hachi dict             # 성격·말투·사전 보기
usagi art              # 아트만 출력
echo "맛있다" | usagi   # 파이프 입력
```

대화 모드 명령어: `/help`, `/dict`, `/explain`, `/char <usagi|chii|hachi>`, `/quit`

시작 화면에는 캐릭터 아트가 나옵니다. 지금은 우사기만 점자 아트가 있고(27칸), 터미널이 좁거나
아트가 없는 캐릭터는 작은 배너를 씁니다.

## 파이썬에서 사용

```python
from usagi import Chatter, Usagi, get_character, say, translate

say("배고파")                          # '쥬르리!'
say("시험 걱정돼", character="hachi")   # '어떻게든 되라앗!'
translate("이얏", character="chii")     # '싫어! / 무서워!'

hachi = Chatter(get_character("hachi"), seed=42)
hachi.reply("내일 비 온대?").text        # '내일 비 온대…라는 거야!?'

Usagi(seed=42).reply("요즘 어때?").text  # '우라!!'
```

## 캐릭터

### 우사기 (`usagi`)
| 표현 | 의미 | 반응하는 입력 예시 |
|---|---|---|
| 야하 | 뭔가를 찾았을 때, 혹은 등장할 때 | 안녕, 찾았다, hello |
| 우라 | 최근 / 거대하다 (상황에 따라 다름) | 요즘, 최근, 거대, big |
| 푸루야 | 공감 요구, 따라오라는 초대, 응원 | 힘들어, 화이팅, 같이 가자 |
| 푸루 | 잡초 이름, 알겠어 | 해줘, 부탁해, ok |
| 하아? | 뭐야?, 놀랐을 때, 어이없을 때 | 뭐?, 왜, 진짜?, 헐 |
| 후응 | 맞아 (긍정의 의미) | 맞지?, 그치, 인정 |
| 쥬르리 | 식욕이 돌 때 | 배고파, 먹고 싶다, 밥 |
| 미야아아 | 어서 오세요 | 다녀왔어, 퇴근, 도착 |
| 우아 | 맛있다 | 맛있다, 존맛, yummy |
| 푸루야우라우라 | 해독 불가능한 기괴한 괴성 | ㅋㅋㅋㅋ, 미쳤다, 대박, !!! |

### 치이카와 (`chii`) — 초안
겁 많은 울보지만 다정한 노력파. 말수가 거의 없고 짧은 감탄사로 기분을 표현합니다.

| 표현 | 원문 | 쓰는 상황 |
|---|---|---|
| 왓 | ワッ | 살짝 놀랐을 때 |
| 와아… | ワァ… | 저도 모르게 소리가 나올 때, 울음이 터질 때 |
| 후! | フ！ | 기쁠 때, 인사할 때 |
| 응 | うん | 동의할 때 |
| 이얏! | イヤッ | 거절할 때, 위험할 때 |
| 야다앗! | ヤダーッ | 강하게 거부할 때 |
| 야앗!! | ヤーッ!! | 맞서거나 스스로를 북돋울 때 |

### 하치와레 (`hachi`) — 초안
밝고 긍정적인 낙천가. 문장으로 말하며 친구들의 마음을 대신 말해주는 통역 역할을 합니다.
상대 말을 받아 **"…라는 거야!?"** 하고 되묻는 게 대표 패턴입니다.

| 표현 | 원문 | 쓰는 상황 |
|---|---|---|
| (상대 말)…라는 거야!? | …ってコト！？ | 놀라거나 새로 알았을 때 |
| 어떻게든 되라앗! | なんとかなれーッ | 막막하거나 위기일 때 |
| 괜찮아! 괜찮아! | だいじょうぶ!だいじょうぶ! | 친구가 힘들어할 때 |
| 서두르지 않아도 괜찮아~ | 焦んなくて大丈夫だよー | 조급해할 때 |
| 기쁘다! 와! | うれしい!ワ! | 기쁠 때 |
| 큰일이다! 위험해! | たいへん!やば! | 갑자기 일이 터졌을 때 |
| 울어버렸다… | 泣いちゃった | 누가 울 때 |
| 기쁨이 없어~ | 喜びがない〜 | 나쁜 일이 겹칠 때 |
| 안 될 것 같으면 그만두면 되지! | だめそうだったらさーリタイアすればいいよね | 도전을 망설일 때 |
| 한 장이라도 좋은 게 있으면 됐지! | 一枚でもいいのがあればさッイイよねッ! | 사진·실패 얘기 |

치이카와·하치와레의 성격과 말투는 팬 정리 사이트를 참고했습니다(공식 설정집 아님).
출처는 각 캐릭터 파일(`src/usagi/characters/chii.py`, `hachi.py`) 상단에 있습니다.
한국어 표기는 일본어 원문을 옮긴 것이라 공식 한국어판과 다를 수 있습니다.

## 캐릭터 추가하기

`src/usagi/characters/` 에 파일을 만들고 `Character` 를 정의한 뒤 `characters/__init__.py` 의
`CHARACTERS` 에 등록하면 됩니다. `rules` 는 위쪽일수록 우선순위가 높고, 매칭이 없으면 `fallback`
에서 무작위로 고릅니다. 새 명령(예: `momonga`)을 만들려면 `cli.py` 에 진입 함수를 추가하고
`pyproject.toml` 의 `[project.scripts]` 에 등록합니다.
